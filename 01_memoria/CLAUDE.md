# Diretrizes de Contexto do Projeto (CLAUDE.md)
*Este arquivo orienta agentes Claude Code / Antigravity / Cursor sobre como operar neste repositório.*

## Regras de Leitura e Escrita
1. Antes de codificar, consulte o arquivo de contexto relevante no diretório `01_memoria/vault_obsidian/`.
2. Para planejar ou criar novas funcionalidades, execute a respectiva skill em `02_habilidades/skills/`.
3. Todo código gerado deve ser compatível com as regras de governança em `01_memoria/vault_obsidian/02_regras_de_negocio.md`.
4. Nunca apague arquivos de benchmark ou logs sem autorização expressa.

## Comandos Úteis
- Iniciar o painel de avaliação e benchmark: `npm start`
- Rodar suíte de testes comparativos via CLI: `npm run benchmark`
